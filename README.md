# Re:Zero · 章节回廊

非官方中文剧情解读站，按 Web 小说大篇章提供世界视角与昴的视角，包含人物对照、因果解读和章节流程图。

## GitHub Pages

站点文件位于 `docs/`，无需安装依赖或构建。仓库的 **Settings → Pages → Deploy from a branch** 选择发布分支与 `/docs`。

`docs/.nojekyll` 保留静态资源的原始结构。链接和资源均使用相对路径，支持项目站点的子目录地址。

## 内容

包含十个篇章、角色当前章节简介、文字颜色区分、手机和平板竖屏布局、左侧抽屉目录。小说内容与心理解读分开呈现，原文及官方图片来源见站内链接。

本副本对应原站第 10 版；访问权限在各托管平台分别设置。私有仓库本身不代表 GitHub Pages 网站私有。
